# LifeCalc

LifeCalc is a simple web-based calculator suite designed to make everyday calculations quick and easy.

## ✨ Features

LifeCalc currently includes 8 calculators:

-  Age Calculator
-  Date Calculator
-  BMI Calculator
-  Tip Calculator
-  Percentage Calculator
-  Discount Calculator
-  Unit Converter
-  Interest Calculator

## Built With

-  HTML
-  CSS
-  JavaScript

No frameworks or external libraries are required.

## Desing

LifeCalc uses a simple cosmic orange and off-white theme with a clean, easy-to-use interface.

## How To Use

1. Open LifeCalc in a web browser.
2. Choose the calculation you need.
3. Enter the required values.
4. Click the calculation button.
5. View your result instantly.
